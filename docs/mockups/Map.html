앱 화면 지도

화면들이 어떻게 이어지는지 — 어떤 화면이 있고, 하루 중 언제 무엇을 쓰고, 어떻게 이동하는지. 예시 데이터는 지어낸 값.

1. 화면과 흐름

초록 표시 = 시안 채택, 호박색 "직원" = 직원도 쓰는 화면(F03: 직원은 마감 · 입고 · 폐기만).

2. 하루 흐름 — 첫 화면을 무엇으로 할까

베이커리의 하루에 맞추면 "오늘" 화면이 시간대마다 맨 위에 보여 줄 것이 달라진다. 점선은 그 기능이 생기는 단계 전까지 비어 있는 자리.

첫 화면 규칙(안): 점주는 늘 "오늘"로 연다. "오늘" 화면이 스스로 바뀐다 — 마감 전이면 맨 위에 "오늘 마감 입력" 버튼(오늘 손실 시안의 "마감 전" 상태 그대로), 마감 후면 오늘 손실, M4부터는 아침에 "오늘 만들 것"이 맨 위. 직원은 "마감"으로 연다. 화면을 시간으로 바꾸지 않고 상태(마감했나)로 바꾼다 — 매장마다 마감 시각이 달라서.

3. 이동 시안

안쪽은 눌러서 이동해 볼 수 있다. 오늘 · 마감은 채택한 시안이 그대로 들어가고, 아직 안 그린 화면은 자리표시.

5. 정할 것

  1. 휴대폰 이동 방식 — A 아래 탭 · B 가운데 마감 버튼 · C 홈에서 들어가기
  2. 데스크톱 이동 방식 — A 왼쪽 메뉴 · B 위쪽 메뉴
  3. 첫 화면 — 위 2절의 규칙(점주는 "오늘", 직원은 "마감", 마감 여부로 바뀜)으로 갈지
  4. 직원에게 금액을 보여 줄지 — 지금 안은 직원에게 "오늘(손실 금액)" · 원가를 숨긴다. 마감 입력 화면 아래의 "오늘 폐기 손실(원가 기준)"도 직원에게는 개수 · 폐기율만 보일지
  5. "내일 권장"의 자리 — M4 전까지는 더보기 안 자리표시, M4부터 "오늘" 화면 맨 위(아침)로
